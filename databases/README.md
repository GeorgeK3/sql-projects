# SQL Projects Repository

This repository contains multiple SQL projects developed as part of the **Data Bases** and **Data Management and Analysis Systems** courses. The projects involve **database design, query optimization, data manipulation, and data analysis** using SQL and Python.

---
## 📌 Project Overviews

### 1️⃣ Project 1: Database User Management
- **File:** `SQLQuery_1.sql`
- **Objective:**
  - Create a database user `examiner`.
  - Assign the `db_datareader` role to allow read access.
- **Technologies Used:** SQL Server.
- **Usage:** Run the script in SQL Server to create the user and assign permissions.

---

### 2️⃣ Project 2: Database Schema & Data Import
- **Files:** `alter_tables.sql`, `import_csv.py`
- **Objective:**
  - Define **primary keys and foreign keys** in a **movie database schema**.
  - Import keyword data from a **CSV file** into SQL tables.
- **Technologies Used:** SQL Server, Python (for CSV processing).
- **Usage:**
  - Run `alter_tables.sql` to define constraints.
  - Execute `import_csv.py` to process and load keyword data.

---

### 3️⃣ Project 3: SQL Query Operations
- **File:** `simple_queries.sql`
- **Objective:** Run **various SQL queries** on a movie database, such as:
  - Retrieving movies based on specific criteria.
  - Aggregating data using `GROUP BY`.
  - Applying `JOIN` operations for relational queries.
- **Technologies Used:** SQL.
- **Usage:** Execute the queries in an SQL environment to extract insights.

---

### 4️⃣ Project 4: Data Integrity & View Creation
- **Files:** `f.inconsistencies.sql`, `remove_duplicates.sql`, `d.alterTables.sql`, `e.createViews.sql`
- **Objective:**
  - Detect and correct **data inconsistencies** in a **movie dataset**.
  - Remove **duplicate entries** to improve data integrity.
  - Alter table structures for better efficiency.
  - Create **SQL views** for optimized querying.
- **Technologies Used:** SQL.
- **Usage:** Run the scripts **in sequence** to clean and structure the database.

---

### 5️⃣ Final Project: Data Analysis & Visualization (SQL + Python)
- **Files:** `project.sql`, `project.py`
- **Objective:** 
  - Analyze **movie datasets** using SQL.
  - Use **Python** for data visualization (**Matplotlib, NumPy, PyODBC**).
  - Execute **complex queries** on movie data to find trends and insights.
- **Technologies Used:** SQL Server, Python.
- **Usage:**
  - Run `project.sql` for **data analysis**.
  - Execute `project.py` to generate **visualizations**.
